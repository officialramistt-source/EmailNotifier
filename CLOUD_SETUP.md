# ☁️ Настройка 24/7 Автономной Работы в Облаке (При выключенном ноутбуке)

Чтобы напоминалки приходили **всегда**, даже когда ноутбук выключен, спит или находится без интернета, мы используем **GitHub Actions (Облако Microsoft)**.

Это на 100% бесплатно (тратит 15 мин из 2000 бесплатных минут в месяц), надежно и безопасно.

---

## 🚀 Пошаговая инструкция (Настройка за 3 минуты)

### Шаг 1. Создать приватный репозиторий на GitHub
1. Зайди на [github.com/new](https://github.com/new).
2. Назови репозиторий, например: `projectAnti`.
3. Обязательно выбери **Private** (Приватный).
4. Нажми **«Create repository»**.

---

### Шаг 2. Загрузить проект в репозиторий
Выполни в терминале в папке `projectAnti`:

```powershell
git init
git add .
git commit -m "feat: 24/7 autonomous email notifier"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН_GITHUB/projectAnti.git
git push -u origin main
```

---

### Шаг 3. Добавить 3 Секрета в GitHub (Безопасность)
Чтобы пароль от почты не лежал в открытом коде:

1. В созданном репозитории на GitHub перейди:
   **Settings** (вверху) -> слева **Secrets and variables** -> **Actions**.
2. Нажми **«New repository secret»** и добавь 3 переменные:
   * **`SENDER_EMAIL`** = `ramishajrutdinoff@yandex.ru`
   * **`RECIPIENT_EMAIL`** = `officialramistt@gmail.com`
   * **`APP_PASSWORD`** = *(твой 16-значный пароль приложения Яндекса)*
